Program Reporting Lines
Management Control Memorandum

From: Office of Program Controls
To: Division Routing Clerks
Subject: Supervisor references for listed program numbers

For current routing, use the accountable supervisor carried on the reporting lines file for the following entries: P-940 accountable supervisor S-977; P-910 accountable supervisor S-931. These are the identifiers presently attached to the listed program numbers in the reporting structure and should be used where a supervisor code is required on internal routing forms.
